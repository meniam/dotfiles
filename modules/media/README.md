# Media

Provides command-line tools for inspecting, converting, and previewing media files.

| Utility | Purpose |
| --- | --- |
| [FFmpeg](https://ffmpeg.org/) | Records, converts, and streams audio and video. |
| [ImageMagick](https://imagemagick.org/) | Converts and manipulates raster images. |
| [MediaInfo](https://mediaarea.net/en/MediaInfo) | Reports technical and tag metadata for media files. |
| [ExifTool](https://exiftool.org/) | Reads and writes metadata in image, audio, video, and document files. |
| [Poppler](https://poppler.freedesktop.org/) | Supplies command-line tools for rendering and extracting content from PDF files. |
| [Chafa](https://hpjansson.org/chafa/) | Renders image previews as terminal graphics or text. |
